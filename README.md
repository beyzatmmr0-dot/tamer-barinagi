# Tamer Barınağı — Evcil Hayvan Sahiplendirme Sistemi

İnternet Programcılığı I dersi için hazırlanmış PHP proje ödevi. Hayvan ilanları, aşı ve bakım takibi, görüşmeler ve sahiplenme kayıtları tek sitede tutulur. Sadece PHP, HTML ve CSS kullanılmıştır (framework yok). Veriler $_SESSION içinde saklanır.

## Projeyi indirme

Projenin tamamı bu depodaki Tamer_Barinagi_PHP_Proje.zip dosyasındadır. Dosyaya tıklayıp sağ taraftaki indirme düğmesine (Download raw file) basın.

## Nasıl açılır (XAMPP ile)

1. ZIP dosyasına sağ tıklayıp "Tümünü ayıkla" deyin. Çıkan Tamer_Barinagi klasörünün içinde index.php, functions.php ve assets klasörü görünmelidir.
2. Bu dosyaları C:\xampp\htdocs\tamerbarinagi klasörüne koyun. index.php doğrudan bu klasörün içinde olmalıdır.
3. XAMPP Control Panel'i açıp Apache satırındaki Start düğmesine basın.
4. Tarayıcıda http://localhost/tamerbarinagi/ adresini açın.

MySQL gerekmez. Sayfa açılmazsa Apache'nin yeşil (çalışıyor) olduğunu kontrol edin.
